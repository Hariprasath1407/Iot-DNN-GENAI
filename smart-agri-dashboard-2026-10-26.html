Future Hardware Integration Architecture Stage 2 Roadmap

Status Transparency: Current prototype uses simulated/manual sensor values. ESP32 integration is planned as a future implementation.
1

ESP32 Microcontroller Core

Low-power 32-bit dual-core microcontroller collecting ADC and digital bus signals.

2

Physical Sensor Bus

Capacitive Soil Moisture, DHT22 (Temp & Humidity), Industrial Soil pH Probe, RS485 Modbus NPK Soil Sensor.

3

Wi-Fi & MQTT / REST Gateway

ESP32 transmits structured JSON telemetry via Wi-Fi 802.11 b/g/n using secure HTTP POST or MQTT broker.

4

Backend Ingestion & Smart Agriculture Dashboard

Validation layer verifies sensor bounds and stores readings into time-series database.

5

Feed-Forward Deep Neural Network (MLP) Crop Prediction

Edge or cloud inference running feed-forward neural net with 7 input features to yield crop suitability scores.

6

Google Gemini Generative AI Assistant & Multilingual Translation

Model synthesizes context into farmer-friendly explanations in Hindi, Tamil, Telugu, Kannada, or English.
